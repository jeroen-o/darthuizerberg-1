# darthuizerberg-1

Statische site (GitHub Pages) voor kantoorruimte huren in Vathorst, Amersfoort — https://www.darthuizerberg1.nl

- `index.html` — één bestand, geen build-step; bevat alle SEO-/geo-metadata en JSON-LD (WebSite, Organization, WebPage, BreadcrumbList, RealEstateListing, Place, FAQPage, ItemList)
- `llms.txt` — samenvatting voor AI-assistenten (GEO)
- `robots.txt`, `sitemap.xml` — crawlers; werk `lastmod` bij na elke inhoudelijke wijziging
- Houd de FAQ in `index.html` (zichtbaar) en in de FAQPage-JSON-LD gelijk
